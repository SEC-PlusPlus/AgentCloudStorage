# M3 开发文档：搜索与回收站

状态：已实现（2026-10-03）。

## 目标与范围

- 按文件名搜索并服务端分页；不搜索文件夹。搜索结果展示后端实际返回的目录 ID，不编造目录路径。
- 回收站列表支持分页、恢复和永久删除；永久删除前二次确认。
- 展示已用存储空间。后端未返回总配额，因此只显示已用字节，不显示虚构的百分比。
- 所有接口错误、空状态、加载状态均有对应反馈；401 清除会话并跳回登录页。

## 使用 API

- `GET /api/v1/files/search?q=&page=&page_size=`
- `GET /api/v1/trash?page=&page_size=`
- `POST /api/v1/files/:id/restore`
- `DELETE /api/v1/trash/:id`
- `GET /api/v1/storage/usage`

## 验收

- 可搜索、翻页、清空关键词并回到目录视图。
- 回收站可查看删除日期、恢复文件和永久删除文件。
- 用量单位可读且不展示未提供的容量配额。
- API 失败后可以重试；永久删除操作有明显确认。

## 实现说明

搜索控件集成在文件工作台工具栏，回收站作为侧栏独立页面；以现有 handler 的字段结构实现。
