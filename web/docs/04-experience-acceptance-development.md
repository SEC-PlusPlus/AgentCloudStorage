# M4 开发文档：体验收尾与验收

状态：已实现（2026-10-03）。

## 目标与范围

- 桌面和窄屏布局适配；手机上仍可切换文件与回收站。
- 提供明确的加载、错误、空状态、成功提示和不可逆操作确认。
- 表单和操作使用原生语义控件；对话框支持 Escape、焦点循环与关闭后焦点归还。
- 装饰粒子低密度绘制、画布只在尺寸变化时重置；尊重 `prefers-reduced-motion`。
- 复查视觉对比度、溢出、错误处理和 API 边界。

## 验收方式

- `npm run build`（包含 `vue-tsc -b`）通过。
- `git diff --check` 无空白错误。
- Vite 开发服务启动，入口 `/` 和深链接 `/login` 返回 HTTP 200。
- 实际文件 API 登录态联调需要 Go 服务、MySQL 和 MinIO 运行；若当前环境不可用，明确记为未联调。

## 已知非目标

当前没有自动化浏览器测试；本轮不实现分片/断点续传、秒传、文件预览、分享、批量操作、Agent 知识库或总容量配置。
