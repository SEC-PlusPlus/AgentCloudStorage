# M9A 登录页动效与品牌符号

状态：实现、生产构建与桌面/390px 视觉验收完成（2026-10-08）；真实登录回归待完成。

## 目标

- 保留用户指定的像素 Go 鼠作为项目角色，新增原创 SVG「文件进入私人仓库」场景；JS 只驱动文件沿路径移动，不让持续动画干扰输入。
- 将全站“云＋对号”改为原创层叠文件匣符号；不借用 Element Plus 或其他网盘的商标。
- 登录和注册使用 Element Plus 的表单、输入框、按钮与提示，保持原有后端接口和校验约束。

## 动画与可访问性

- SVG 文件沿贝塞尔路径缓慢移动，静止时也能理解图意；`requestAnimationFrame` 在组件卸载时取消。
- 尊重 `prefers-reduced-motion`，减少动态效果；装饰 SVG 不进入读屏顺序。
- 在窄屏优先保留表单，动效缩小但不遮挡输入。

## 验收

- 登录、注册、错误和成功提示仍能工作；键盘可操作。
- SVG 动画不会在离开页面后继续运行，不出现横向滚动。
- 新 Logo 在登录页与登录后侧栏一致，不再含对号。

## 实现与验证记录

- `StorageScene.vue` 使用内联 SVG 路径和 `requestAnimationFrame` 移动文件图标，保留像素 Go 鼠；卸载时取消帧，响应减少动态效果偏好。
- `BrandMark.vue` 改为原创层叠文件匣；`AuthPage.vue` 使用 Element Plus 表单、输入框、按钮和状态提示。
- `npm run build` 通过；本机 Chrome 桌面和 390px 视口截图检查无横向溢出，SVG 场景与表单均可见。
