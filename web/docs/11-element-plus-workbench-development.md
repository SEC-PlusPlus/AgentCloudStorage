# M9C Element Plus 文件工作台与回收站

状态：展示层重构、生产构建与模拟数据交互检查完成（2026-10-08）；真实 API 回归待完成。

## 目标

- 在文件工作台和回收站用 Element Plus 统一搜索输入、主次按钮、状态提示、上传进度、更多菜单、分页和操作表单。
- 保留自定义文件行：文件名、大小、时间和操作区仍适配长文件名、窄屏与问答入口。
- 保留现有分片上传、预览、问答、目录与回收站逻辑；仅替换展示层与控件事件。

## 交互约束

- 上传仍调用现有自写分片上传逻辑，不让 `ElUpload` 发送第二套请求。
- 破坏性操作需要确认；菜单被键盘可达且关闭后不遗留浮层。
- 原有自定义预览和问答对话框暂保留，避免同时重写焦点与异步生命周期；内部输入与按钮统一组件风格。

## 验收

- `npm run build` 通过；搜索、上传、取消、预览、问答、文件/文件夹操作和回收站入口保留。
- 窄屏不溢出，长文件名截断而不遮住操作。
- 无后端时提供明确错误；真实 API 手动回归单独记录。

## 实现与验证记录

- 文件工作台与回收站使用 Element Plus 搜索、按钮、进度、状态提示、空状态、分页及确认框；文件行仍由项目控制布局。
- 文件和文件夹“更多”使用组件库菜单；模拟数据检查“更多 → 重命名”能打开原对话框。
- 上传仍用原有文件选择与分片上传流程，未启用 `ElUpload` 的默认请求。
- `npm run build` 通过；真实登录、上传、取消、预览、问答及回收站操作仍需连接本地中间件后回归。
