# M8 登录后工作台视觉重构

状态：代码与生产构建完成（2026-10-06）；浏览器视觉及真实操作待用户验收。

## 目标

把登录后的文件工作台与回收站从深色、发光、装饰较多的视觉，改为适合日常文件管理的朴素浅色界面。保留已有业务功能、登录页与接口契约，不复制百度网盘或夸克网盘的品牌素材。

## 参考与取舍

- 参考百度网盘网页版的「侧栏 + 顶部操作 + 文件列表」信息结构。
- 参考夸克网盘帮助文档中强调的文件列表浏览、直接预览与清晰操作。
- 不借用两者的 Logo、插画或具体页面样式；本项目使用柔和中性色、单一蓝色主按钮、圆角和轻边框建立自己的视觉。

## 视觉规范

- 页面底色为暖灰白，内容区为白色；避免玻璃拟态、荧光边框、噪点粒子和大面积渐变。
- 侧栏保持窄而稳定，导航只突出当前所在位置；减少英文装饰语与像素符号。
- 主操作按钮使用中等圆角，次级按钮浅色描边；文件行留足高度，常用操作靠近文件名，低频操作收在“更多”菜单。
- 桌面与窄屏保持一致的操作语义，不依赖悬停才能发现按钮。

## 本模块改动范围

- `AppShell.vue`：整理品牌、导航与顶栏文案。
- `FileWorkbench.vue`、`TrashPage.vue`：简化标题、说明、空状态和操作区；功能代码保持不变。
- 新增独立的登录后主题 CSS，避免影响登录页。

## 验收

- 文件列表、搜索、上传、文件夹操作、预览、问答、回收站功能入口都保留。
- 小屏下按钮与菜单可触达，文件名不过度挤压。
- 弹窗、错误、加载状态与主页面配色一致，键盘焦点清晰。
- `npm run build` 通过；视觉截图与交互需浏览器手动验收。

## 实现记录

- `web/src/workspace-light.css` 提供仅在 `.app-shell` 内生效的浅色主题，登录页不受影响。
- `web/src/layouts/AppShell.vue` 精简侧栏和顶栏，移除静态装饰卡片与像素符号。
- `web/src/pages/FileWorkbench.vue` 简化标题和空状态，常用文件操作改为文字按钮，低频操作放进“更多”菜单；问答、预览、上传、搜索逻辑保留。
- `web/src/pages/TrashPage.vue` 统一回收站标题、空状态与操作文案。
- `npm run build` 已通过；尚无自动视觉快照测试。
