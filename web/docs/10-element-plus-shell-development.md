# M9B Element Plus 应用外壳

状态：实现、生产构建与模拟登录态视觉验收完成（2026-10-08）；真实登录回归待完成。

## 目标

- 接入 Vue 3 对应的 Element Plus，使用局部组件导入，不在业务代码中复制组件库源码。
- 保留现有路由和账号状态；以 Element Plus 按钮、头像和菜单统一退出入口与导航反馈。
- 视觉采用低饱和蓝、暖白底、细分隔线和圆角；组件库是交互基础，不采用其默认后台模板外观。

## 验收

- 桌面和手机宽度下导航可见，退出登录仍清理会话。
- 新 Logo 在登录页和侧栏清晰一致；路由结构不变。
- 不修改 Go 后端或 API 契约。

## 实现与验证记录

- Vite 按需解析 Element Plus 组件；`App.vue` 设置中文区域；应用外壳使用组件库头像、面包屑和退出按钮，侧栏保留路由语义并采用组件库图标。
- 通过本地模拟登录态检查桌面和 390px 工作台，页面宽度无溢出；未写入真实数据库。
