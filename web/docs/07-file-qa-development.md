# M7 单文件资料问答开发文档

状态：前端实现及构建完成（2026-10-06）；真实账号与文件问答待用户手动验收。

## 目标与范围

在文件工作台对 `.txt`、`.md` 文件提供“向文件提问”入口。用户输入问题，前端调用受登录保护的 `POST /api/v1/knowledge/ask`，展示模型回答。仅接入当前后端已有的单文件问答能力，不增加对话历史、跨文件搜索或流式输出。

## 交互与数据流程

1. 文件操作区仅对 TXT/Markdown 展示提问按钮；点击后打开沿用工作台视觉语言的对话面板。
2. 面板显示目标文件名、适用范围和 500 字符的问题输入限制；提交时调用现有 Bearer 认证的请求封装，发送 `{file_id, question}`。
3. 请求中禁用重复提交，显示等待状态；成功后以纯文本显示回答，保留换行和模型输出的 `[段落编号]`。
4. 失败时在面板内显示可重试提示。关闭面板时取消未完成的前端请求，避免旧文件的回答显示到新文件上。

## 边界与安全

- 前端扩展名限制只为避免无效操作；真正的文件类型、文件归属和内容限制仍由后端处理。
- 不使用 `v-html` 渲染问题或回答；模型的引用编号暂不作为准确性证明。
- 文件超过后端文本/上下文限制时，展示后端的当前失败提示；不在浏览器偷偷截取文件后提问。
- API Key 不进入前端，浏览器只携带已有用户登录令牌请求 Go 后端。

## 验收

- TXT/Markdown 文件出现提问入口，其余类型没有；搜索结果中的文件也可提问。
- 可以提问、等待、看到回答、修改问题后再次提问；空问题不能提交。
- 未登录、文件不存在、网络失败可见错误；关闭或切换目标文件不显示过期回答。
- `npm run build` 通过，并启动前后端供真实账号手动联调。

## 实现记录

- `web/src/api/knowledge.ts` 使用现有请求封装和登录令牌调用问答 API，支持取消请求。
- `web/src/pages/FileWorkbench.vue` 增加 TXT/Markdown 文件入口、问答面板、等待与错误状态、键盘焦点控制。
- `web/src/workbench.css` 延续文件工作台的深色文档风格，补充响应式面板与操作按钮样式。
- 前后端启动后，前端首页、后端健康检查及 Vite 代理均返回 200；问答接口未登录请求返回 401。真实带文件问答尚待用户验证。
